# OTClient V9 by L3K0T

Histórico público de alterações do OTClient V9.

## 20 de novembro de 2026

- **Interface Retro**. O painel de atalhos passou a usar toda a largura disponível. As barras de vida e mana sobre o mapa ficam ocultas quando a barra superior está ativa.
- **Inicialização e encerramento**. Os atalhos são devolvidos aos módulos que os criaram. Efeitos opcionais com texturas indisponíveis deixam de interromper o carregamento do módulo.
- **Beta 1**. Integração das correções de inicialização de Controller, Cyclopedia, Analyser, Health Circle e Taskboard.
